FAQ

      
Questions & answers

    

    

      
What is Vektor?
A code-first assistant. It answers with the code first and keeps the talk to a sentence or two. It runs on Claude, Anthropic's model family, through our own API.

      
Which model does it use?
The current model is shown live in the playground sidebar and the Live section. By default it is Claude Opus 5.5, with Anthropic's server-side fallback switched on.

      
Is it free?
Yes for visitors, within a per-visitor rate limit. There is no account and no API key to set up.

      
Is my code stored?
Vektor keeps the conversation in your browser tab only. It is sent to our API and to Anthropic to produce the answer and is not saved by this site. Close the tab and it is gone.

      
How does ▶ Run work?
JavaScript runs in a Web Worker in your browser and is stopped after 5 seconds. Python runs in Pyodide, which downloads once (about 10 MB) the first time you use it. Nothing runs on our servers.

      
Can I trust the Solidity it writes?
Treat it as a strong first draft. Compile it, test it, and get an audit before a contract holds real funds.

      
Is Vektor affiliated with Anthropic?
No. Vektor is an independent project that uses the Claude API.

      
Is there a token?
The contract address is shown at the top of the page once it is live. Until then it says "Soon". Nothing on this site is financial advice.
